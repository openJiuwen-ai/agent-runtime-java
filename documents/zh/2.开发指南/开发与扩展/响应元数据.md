# 响应元数据增量契约

响应元数据是一次成功执行的附加结果，不是请求 metadata、模型输入，也不是工具 answer 的外层包装。
Runtime 只提供传递和隔离机制，不识别服务带出或任何行业字段。

## 公共接口

| 接口 | 增量变化 | 兼容行为 |
| --- | --- | --- |
| QueryResponse | 可选 metadata Map，新增三参数构造器 | 旧构造器不变；空字段不序列化 |
| QueryStreamObserver | default onComplete(QueryResponse) | 默认调用旧 onComplete()，不强迫已有 observer 改造 |
| RemoteCallOutcome | responseMetadata，新增完整构造器 | 五／六参数构造器仍可使用 |
| ServeRequest | 内部 remoteResponseMetadata | JsonIgnore：不对外接收入参，也不进入请求 JSON 快照 |

流式完成对象中的 result 可以为空：内容此前已经通过 onNext 发送，消费者只需要读取 metadata。
无元数据的内置生产者仍调用旧无参完成方法，避免改变老 observer 的调用方式。
Query 非流式 HTTP 响应可返回顶层 metadata；现有流式协议适配器默认不生成新的可见事件。

## 扩展接入边界

Runtime 在 Agent Handler 的同步、流式和同步转流式回退路径中，按当前请求提取成功终态的
response metadata；不通过 conversationId 查找全局对象。默认实现返回空 Map，宿主或上层扩展
可以通过 Runtime 提供的扩展点提供本次请求需要导出的结构化数据。

Runtime 不规定请求级收集器、访问器、配置开关、Session 映射方式，也不规定 metadata 中的业务字段。
这些内容由宿主或上层扩展自行实现；业务负责决定哪些字段写入、如何校验和裁剪，以及是否把远端
metadata 映射到自己的 Session、Rail 或 Skill 输入。

Runtime 不自动把远端 metadata 交给 LLM，也不把它追加为对话历史或工具结果文本。

## A2A 传输

- 原业务 artifact 仍用 _agentcore_terminal 标识终态正文。
- 业务通过 QueryResponse.metadata 设置本次成功响应的结构化元数据；Runtime 不解析其中的业务字段。
- A2A 完成态通过 TaskStatusUpdateEvent.metadata 承载保留键 _agentcore_response_metadata；SDK 将其合并到最终 Task.metadata。
- 不创建空 TextPart 或响应元数据 Artifact；业务正文及终态 Artifact 保持原样。
- 远端仅从 TASK_STATE_COMPLETED 的 Task.metadata 读取；失败、中断、取消不导出。
- 原生 A2A 单消息响应仍从 Message.metadata 的同一保留键读取；流式完成事件只发送一次。

## 远端调用恢复

成功的 RemoteCallOutcome.responseMetadata 保存到对应 batch member，不混入 result。
BatchResolution.responseMetadata 按 toolCallId 分组，不对不同调用的同名字段做覆盖合并。

当 resume=true：

- runtime.remoteToolResults 保持原有文本／结构化错误结果。
- ServeRequest.remoteResponseMetadata 携带独立的工具调用映射。
- 上层扩展或宿主将该映射放入自己的请求上下文或 Session，供业务逻辑按 toolCallId 读取。
- 应答元数据不会进入 ServeRequest.metadata 或 runtime.request_context，更不会成为下一次远端调用的入参。

当 resume=false：单成员直接保留远端 metadata，多成员以 toolCallId 为键返回各自 metadata。
中间 INPUT_REQUIRED 的成功成员 metadata 随 batch snapshot 存储，恢复同一 batch 可用；
这是未完成业务的恢复状态，不是把上一轮已结束的应答复用到新业务。

本地恢复后的 Agent 不自动把子 Agent 元数据作为自己的应答；需要导出的字段必须由业务重新显式写入。

## 验证与升级

回归覆盖旧回调／构造器、Query JSON 隔离、A2A artifact 与 Message、同步与流式、batch 快照、
远端 metadata 不混入工具结果、失败／中断／取消与重复完成。
下游宿主或扩展使用这些接口时，需要依赖匹配版本的 Runtime；本契约不规定具体业务 SPI，也不自动调整
下游业务的依赖或接入方式。
