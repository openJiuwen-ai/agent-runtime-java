# 架构概述

本文从 **实现模块** 角度说明当前仓库结构；**完整逻辑架构**（中间件、Gateway、Manager、Session、外部服务）见 [逻辑架构](逻辑架构.md)。

---

## 1. 逻辑架构在仓库中的位置

`agent-runtime-java` 是 **Agent Distributed Runtime** 的 Java 实现载体。目标逻辑分层如下（**粗体**为当前仓库已交付或 Submodule 部分）：

| 逻辑区域 | 核心块 | 本仓库 |
| --- | --- | --- |
| 中间件 | Redis、NFS、OBS、DMQ、Database | ⏳ Adapters 对接（结构预留） |
| Agent Gateway | Channel Manager、Message Handler、Cron | 🔌 机构网关；Service 提供 HTTP Query |
| **Agent Runtime Manager** | Deployer、Registry、Discovery、Communication | ⏳ 规划 `manager/*` |
| Session | Lifespan、Isolation、Affinity | Core + Service；亲和靠网关/外置 Session |
| **Agent Server** | **Agent-App**、**Agent-Core**、**Adapters** | ✅ **`service/`** + **`vendor/agent-core-java`** |
| 运行时基础设施 | Yuanrong、Spring Cloud、Docker/K8s | ⏳ Manager deploy **mode** |
| 外部服务 | LLM、MCP、A2A、RAG、Sandbox、OTEL | Core + ⏳ External Adapters / 平台 A2A |

```text
┌──────────┬─────────────────────────────────────────┬──────────┐
│ 中间件    │  Gateway · Manager · Session · Agent Server │  LLM/MCP │
│          │         ↑ 本仓主交付：Agent Server          │  A2A…    │
└──────────┴─────────────────────────────────────────┴──────────┘
```

## 2. 当前仓库组成

```text
agent-runtime-java
├── vendor/agent-core-java     # ① Agent-Core（Submodule）
└── service/                   # ② Agent Server
    ├── agent-service-spec
    ├── agent-service-adapters
    ├── agent-service-app
    └── agent-service-demo
```

规划目录（尚未入仓，与逻辑架构对齐）：

```text
manager/                       # Agent Runtime Manager
applications/                  # 平台 A2A Service 等
```

| 模块 | Maven artifact | 对应逻辑块 |
| --- | --- | --- |
| **spec** | `agent-service-spec` | Agent-App 契约、SPI |
| **adapters** | `agent-service-adapters-*` | Adapters（FW / Middleware / External） |
| **app** | `agent-service-app` | Agent-App：Init、Shutdown、Query、Interrupt |
| **demo** | `agent-service-demo` | 可运行示例 |
| **agent-core-java** | `agent-core-java` | Agent-Core |

**依赖方向**：`app` → `adapters` → `spec`；`app` **不**强依赖某一 adapter leaf（由产品镜像选择）。

## 3. Agent Server 数据面调用链

所有对话请求必须经统一编排（**Agent-App · Query** 路径）：

```text
┌─────────────────────────────────────────┐
│  Ingress（Controller）                   │
│  QueryMvcController / QueryWebFluxController │
│  HealthController / ResetConversationController │
└──────────────────┬──────────────────────┘
                   ▼
┌─────────────────────────────────────────┐
│  ServeOrchestrator                      │
│  · 注册/注销活动流（Interrupt）          │
└──────────────────┬──────────────────────┘
                   ▼
┌─────────────────────────────────────────┐
│  AgentHandler（Adapters · Agent FW）     │
└──────────────────┬──────────────────────┘
                   ▼
         Agent-Core Runner / 远端 HTTP
```

| Agent-App 能力 | 实现位置 |
| --- | --- |
| **Init** | `DefaultAgentLifecycleManager.runInitPhase`、InitHook |
| **Shutdown** | ShutdownHook、`AgentHandler.stop()` |
| **Query** | Query Controller → Orchestrator |
| **Interrupt** | `AgentLifecycleManager.interrupt`（进程内，无 REST） |

**禁止**：Controller 或 A2A 适配层直接调用 `Runner`。

---

## 4. Ingress 与 Egress

| 方向 | 本期能力 | 逻辑 / 模块 |
| --- | --- | --- |
| **Ingress** | Query REST、health、reset | Agent-App · Message Handler（HTTP） |
| **Egress** | Versatile HTTP | Adapters · External Svc |
| **出站（规划）** | MCP、Plugin、A2A Client | External Svc SPI |

进程内 **A2A Server** 不在 Agent Server P0；平台 **A2A** 为独立应用，见 [A2A 与平台边界](A2A与平台边界.md)。

---

## 5. 与 Manager、Gateway 的关系

```text
【控制面 · 部署一次】Agent Runtime Manager
  deploy → DeploymentRecord → GatewayRegistrar（机构网关）

【数据面 · 每次对话】
  网关 / Client → Agent Server /query
  （不经过 Manager）

【平台 A2A · 规划】
  A2A Client → A2A Service → Agent Server /query
```

Agent Server **不自注册**；对外 `url` 由 Manager + 机构网关产生。

---

## 6. Adapters 聚合结构

```text
agent-service-adapters/
├── agent-service-adapters-common      → Middleware / External 包结构
├── agent-service-adapters-agentcore   → Agent FW → Core
├── agent-service-adapters-agentcore-ext
└── agent-service-adapters-versatile   → External → Versatile HTTP
```

各 leaf 使用独立根包（如 `com.openjiuwen.service.adapters.agentcore`），避免 split package。

## 7. 配置与自动装配

Spring Boot 加载：

- `com.openjiuwen.service.app.autoconfigure.AgentServiceAutoConfiguration`
- 各 adapter 的 `*AdaptersAutoConfiguration`

关键前缀：`openjiuwen.service.*`（见 [Adapters 与 Handler](Adapters与Handler.md)）。

框架宿主：**Spring Boot**（本仓默认）；Python 对标 FastAPI；元戎 FaaS 为机构扩展宿主。
