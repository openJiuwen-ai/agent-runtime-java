# 架构概述

本文说明 **`agent-runtime-java` 仓库内已交付的 Java 模块**（当前以 `service/` 为主），及其在整体 **Agent Distributed Runtime** 蓝图中的位置。跨语言全景见 [逻辑架构](逻辑架构.md)。

**两层映射（请勿混用）**：

| 概念 | 架构图 | 本仓库路径 |
| --- | --- | --- |
| **Runtime（Java）** | Agent Distributed Runtime 大框 | **`agent-runtime-java` 整仓** |
| **Agent Server** | Runtime 内的 Server 子块 | **`service/`** |
| **Agent-Core** | Server 内的执行内核 | **`agent-core-java`**（Maven 依赖） |

Python 为 **同级 Runtime 仓库** + 其内的 Agent Server（FastAPI / Yuanrong 等），与 Java **同图、不同仓**。

---

## 1. 逻辑架构在仓库中的位置

`agent-runtime-java` 是 **Agent Distributed Runtime 的 Java 实现仓库**（对应架构图中间 Runtime 大框）。当前 **已入仓交付以 `service/`（Agent Server）为主**；`manager/*` 等将随版本在本仓扩展。

| 逻辑区域 | 核心块 | 本仓库 |
| --- | --- | --- |
| 中间件 | Redis、NFS、OBS、DMQ、Database | ✅ Redis Checkpointer / A2A TaskStore；其余占位 |
| Agent Gateway | Channel Manager、Message Handler、Cron | 🔌 机构网关；Service 提供 HTTP Query |
| **Agent Runtime Manager** | Deployer、Registry、Discovery、Communication | ⏳ 规划 `manager/*`（**本仓**） |
| Session | Lifespan、Isolation、Affinity | Core + Service；亲和靠网关/外置 Session |
| **Agent Server** | **Agent-App**、**Agent-Core**、**Adapters**、宿主 | ✅ **`service/`** + Spring Boot（Python 侧为同级 Agent Server + FastAPI 等） |
| 运行时基础设施 | Yuanrong、Spring Cloud、Docker/K8s | ⏳ Manager deploy **mode** |
| 外部服务 | LLM、MCP、A2A、RAG、Sandbox、OTEL | Core + 本仓 MCP/Remote/Sandbox egress + 进程内 A2A |

```text
┌──────────┬─────────────────────────────────────────┬──────────┐
│ 中间件    │  Gateway · Manager · Session · Agent Server │  LLM/MCP │
│          │    agent-runtime-java = Runtime（Java）   │  A2A…    │
│          │    service/ = Agent Server（当前主交付）    │          │
└──────────┴─────────────────────────────────────────┴──────────┘
```

## 2. 当前仓库组成

```text
agent-runtime-java/            # Agent Distributed Runtime（Java 仓）
├── service/                   # Agent Server（Agent-Core 为 Maven 依赖）
│   ├── agent-service-spec
│   ├── agent-service-adapters
│   ├── agent-service-app
│   └── agent-service-demo
├── manager/（规划）           # Agent Runtime Manager
└── applications/（规划）
```

| 模块 | Maven artifact | 对应逻辑块 |
| --- | --- | --- |
| **spec** | `agent-service-spec` | Agent-App 契约、SPI |
| **adapters** | `agent-service-adapters-*` | Adapters（FW / Middleware / External） |
| **app** | `agent-service-app` | Agent-App：Init、Shutdown、Query、A2A、Interrupt |
| **demo** | `agent-service-demo` | 可运行示例 |
| **agent-core-java** | `agent-core-java` | Agent-Core |

**依赖方向**：`app` → `adapters` → `spec`；`app` **不**强依赖某一 adapter leaf（由产品镜像选择）。

## 3. Agent Server 数据面调用链

所有对话请求必须经统一编排（**Agent-App · Query** 路径）：

```text
┌─────────────────────────────────────────┐
│  Ingress（Controller）                   │
│  QueryMvcController / QueryWebFluxController │
│  HealthController / ResetConversationController │
└──────────────────┬──────────────────────┘
                   ▼
┌─────────────────────────────────────────┐
│  ServeOrchestrator（默认 A2A 增强实现）   │
│  · 活动流注册 / cancelActive            │
│  · a2a_delegate 中断-恢复（可选）       │
└──────────────────┬──────────────────────┘
                   ▼
┌─────────────────────────────────────────┐
│  AgentHandler（Adapters · Agent FW）     │
└──────────────────┬──────────────────────┘
                   ▼
         Agent-Core Runner / 远端 HTTP
```

| Agent-App 能力 | 实现位置 |
| --- | --- |
| **Init** | `DefaultAgentLifecycleManager.runInitPhase`、InitHook |
| **Shutdown** | ShutdownHook、`AgentHandler.stop()` |
| **Query** | Query Controller → Orchestrator |
| **Interrupt** | `AgentLifecycleManager.interrupt`（进程内，无 REST） |

**禁止**：Controller 或 A2A 适配层直接调用 `Runner`。

## 4. Ingress 与 Egress

| 方向 | 能力 | 逻辑 / 模块 |
| --- | --- | --- |
| **Ingress** | Query REST、`/health`、`/reset_conversation` | `agent-service-app` Controller |
| **Ingress** | 进程内 A2A（Agent Card、JSON-RPC） | `controller.a2a` |
| **Egress · 中间件** | Checkpointer（内存 / Redis） | `adapters-common.middleware` → `adapters-agentcore.middleware` → `RunnerConfig` |
| **Egress · 外部** | MCP、出站 Remote（A2A）、Sandbox | `adapters-common.external` DFX + `adapters-agentcore.external` → Core SPI |

Ingress 契约见 [HTTP 对话面](HTTP对话面.md)；中间件与外部服务配置见 [Adapters 与 Handler](Adapters与Handler.md)。进程内 A2A 与平台级 A2A 网关边界见 [A2A 与平台边界](A2A与平台边界.md)。

## 5. 与 Manager、Gateway 的关系

```text
【控制面 · 部署一次】Agent Runtime Manager
  deploy → DeploymentRecord → GatewayRegistrar（机构网关）

【数据面 · 每次对话】
  网关 / Client → Agent Server /query
  （不经过 Manager）

【平台 A2A · 规划】
  A2A Client → A2A Service → Agent Server /query
```

Agent Server **不自注册**；对外 `url` 由 Manager + 机构网关产生。

## 6. Adapters 聚合结构

```text
agent-service-adapters/
├── agent-service-adapters-common
│   ├── middleware          # Redis 客户端、MiddlewareProperties、Checkpointer 配置组装
│   ├── external            # 外部调用 DFX（超时 / 重试 / 熔断 / 审计）
│   └── credential          # 凭证解密
└── agent-service-adapters-agentcore
    ├── agentfw             # JiuwenCoreAgentHandler
    ├── middleware          # 写入 RunnerConfig（Checkpointer）
    └── external            # MCP / Remote / Sandbox 注册到 Core SPI
```

扩展 Handler（中断、远端低码等）不在本仓 adapters 内；由业务镜像 `@Bean AgentHandler` 或外部模块提供。配置与示例见 [Adapters 与 Handler](Adapters与Handler.md)。

## 7. 配置与自动装配

Spring Boot 加载：

- `com.openjiuwen.service.app.autoconfigure.AgentServiceAutoConfiguration`
- 各 adapter 的 `*AdaptersAutoConfiguration`

关键前缀：`openjiuwen.service.*`（见 [Adapters 与 Handler](Adapters与Handler.md)）。

框架宿主：**Spring Boot**（Java 本仓）；整体 Runtime 还包括 Python **FastAPI**、**Yuanrong FaaS** 等，见 [逻辑架构](逻辑架构.md)。
