# paths

`com.openjiuwen.service.spec.paths` 定义 Agent Service 对外暴露的路径常量。

## 类型

| Type | Description |
| --- | --- |
| [`AgentServicePaths`](paths/AgentServicePaths.md) | HTTP Query、health、reset 路径。 |
| [`A2AServicePaths`](paths/A2AServicePaths.md) | Agent Card 和 A2A JSON-RPC 路径。 |
