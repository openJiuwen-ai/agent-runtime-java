# com.openjiuwen.service.spec.paths.A2AServicePaths

## class A2AServicePaths

```java
public final class A2AServicePaths
```

A2A Agent Card 与 JSON-RPC 路径常量。

## 常量

| Constant | Value | Description |
| --- | --- | --- |
| `WELL_KNOWN_AGENT_CARD` | `/.well-known/agent-card.json` | 标准 Agent Card 路径。 |
| `WELL_KNOWN_AGENT_JSON` | `/.well-known/agent.json` | 兼容路径。 |
| `A2A_PREFIX` | `/a2a` | A2A mount prefix。 |
| `A2A_JSONRPC` | `/a2a/` | JSON-RPC 主入口，带尾斜杠。 |
| `A2A_JSONRPC_NO_SLASH` | `/a2a` | JSON-RPC 主入口，不带尾斜杠。 |
| `A2A_WELL_KNOWN_CARD` | `/a2a/.well-known/agent-card.json` | prefixed card 兼容路径。 |
