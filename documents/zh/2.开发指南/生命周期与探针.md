# 生命周期与探针

Agent Service 在 Spring 容器启停时执行 **Init / Shutdown** 阶段，并通过 `/health` 暴露就绪状态。流式执行支持进程内 **interrupt**（无 REST）。

## 生命周期阶段

```text
Spring ContextRefreshed
  → AgentLifecycleBootstrap
  → DefaultAgentLifecycleManager.runInitPhase()
      → InitPhaseExecutor（@Order InitHook）
      → AgentHandler.start()
      → agent_loaded = true

Spring ContextClosed
  → runShutdownPhase()
      → AgentHandler.stop()
      → ShutdownHook
```

Init **fail-fast**：任一 InitHook 失败则 `agent_loaded` 保持 false，readiness 不应放流。

## 就绪与探针

| 信号 | 来源 | HTTP 字段 |
| --- | --- | --- |
| 进程存活 | Spring 已启动 | `process_up` |
| Agent 可接单 | Init 完成 | `agent_loaded` |

Manager 与网关在 deploy 后探测 `GET /health`，**不承担**服务注册（Issue #8）。

## SPI 扩展

| 接口 | 用途 |
| --- | --- |
| `AgentInitHook` | 预热缓存、校验外部依赖 |
| `AgentShutdownHook` | 释放连接、刷盘 |
| `AgentInterruptHandler` | interrupt 时业务清理 |
| `AgentReadiness` | 自定义就绪逻辑（默认 `DefaultAgentReadiness`） |

Hook 通过 Spring 收集；InitHook 支持 `@Order`。

## 流式执行与 interrupt

```text
streamQuery 开始
  → ActiveStreamRegistry.register(conversationId, handle)
  → AgentHandler.streamQuery
  → onComplete / onError → unregister

AgentLifecycleManager.interrupt(conversationId)
  → ActiveStreamInterruptor
  → 取消注册的活动流
  → AgentInterruptHandler（若注册）
```

- **interrupt**：停止**当前**流式 run，会话 ID 可保留。
- **reset_conversation**：清空会话状态，见 [HTTP 对话面](HTTP对话面.md)。

A2A `tasks/cancel` 规划在 **平台 A2A Service**；深取消可再调 Lifecycle interrupt。

## 配置

前缀 `openjiuwen.service.lifecycle`（`LifecycleProperties`）控制生命周期相关开关（以源码为准）。

## Handler 启停

`AgentHandler.start()` / `stop()` 在 Init / Shutdown 阶段各调用一次，用于 `Runner.start()` 等引擎级资源。
