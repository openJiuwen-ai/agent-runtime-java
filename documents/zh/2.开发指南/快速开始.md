# 快速开始

本文说明如何在本地构建 **agent-runtime-java** 并运行最小 **Agent Service** 示例。

## 前置条件

| 项 | 要求 |
| --- | --- |
| Java | 17+ |
| Maven | 3.9+ |
| agent-core-java | Maven 依赖 `com.openjiuwen:agent-core-java:0.1.12`；源码分支 `feature/630`（见根 `pom.xml` 中 `agent-core.version`） |

本地与流水线需先 **clone `agent-core-java` 仓库并 checkout `feature/630` 分支**（Maven 版本 `0.1.12`，见根 `pom.xml` 中 `agent-core.version`），执行 `mvn install` 将 jar 安装到本地 Maven 仓库（或从机构私服拉取同版本制品）。本仓 **不再** 通过 Git Submodule / `vendor/` 携带 Core 源码。

```bash
git clone https://gitcode.com/openJiuwen/agent-core-java.git
cd agent-core-java
git checkout feature/630
mvn clean install -DskipTests
```

## 克隆本仓

```bash
git clone https://gitcode.com/openJiuwen/agent-runtime-java.git
cd agent-runtime-java
```

## 全量构建

在仓库根目录：

```bash
mvn clean install -DskipTests
```

仅构建并测试 Service 层：

```bash
cd service
mvn clean test
```

## 运行 Demo

```bash
cd service
mvn -pl agent-service-demo -am spring-boot:run
```

默认端口 **8090**。Demo 在无 LLM 配置时使用 **mock handler**，返回 `demo:<message>`。

强制 mock：

```bash
mvn -pl agent-service-demo -am spring-boot:run \
  "-Dspring-boot.run.arguments=--openjiuwen.demo.llm.enabled=false"
```

## 第一条 Query

健康检查：

```bash
curl -s http://localhost:8090/health
```

非流式：

```bash
curl -s http://localhost:8090/v1/query \
  -H 'Content-Type: application/json' \
  -d '{"conversation_id":"c1","message":"hello","stream":false}'
```

流式 SSE：

```bash
curl -N http://localhost:8090/v1/query \
  -H 'Content-Type: application/json' \
  -d '{"conversation_id":"c1","message":"hello","stream":true}'
```

## 接入真实大模型

1. 复制 `service/agent-service-demo/apiconfig_example.json` 为 `apiconfig.json` 并填写密钥（亦可参考 [agent-core-java examples](https://gitcode.com/openJiuwen/agent-core-java/tree/feature/630/examples)）。
2. 将文件放在工作目录或通过 `OPENJIUWEN_API_CONFIG` 指定路径。
3. 重启 demo；链路变为 `Query → Orchestrator → JiuwenCoreAgentHandler → Runner → LlmAgent`。

详见 [agent-service-demo/README.md](../../../service/agent-service-demo/README.md)。
