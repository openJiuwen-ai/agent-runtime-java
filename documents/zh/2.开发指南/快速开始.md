# 快速开始

本文说明如何在本地构建 **agent-runtime-java** 并运行最小 **Agent Service** 示例。

## 前置条件

| 项 | 要求 |
| --- | --- |
| Java | 17+ |
| Maven | 3.9+ |
| agent-core-java | 见 [Agent Core 依赖](Agent Core 依赖.md)（版本与分支以根 `pom.xml` 为准） |

本地构建 Core 的步骤见 [Agent Core 依赖 · 本地安装 Core（源码）](Agent Core 依赖.md#本地安装-core源码)。本仓 **不再** 通过 Git Submodule / `vendor/` 携带 Core 源码。

## 克隆本仓

```bash
git clone https://gitcode.com/openJiuwen/agent-runtime-java.git
cd agent-runtime-java
```

## 全量构建

在仓库根目录：

```bash
mvn clean install -DskipTests
```

仅构建并测试 Service 层：

```bash
cd service
mvn clean test
```

## 运行 Demo

```bash
cd service
mvn -pl agent-service-demo -am spring-boot:run
```

默认端口 **8090**。Demo 固定使用真实 Core 链路，启动前必须配置 LLM。

## 第一条 Query

健康检查：

```bash
curl -s http://localhost:8090/health
```

非流式：

```bash
curl -s http://localhost:8090/v1/query \
  -H 'Content-Type: application/json' \
  -d '{"conversation_id":"c1","message":"hello","stream":false}'
```

流式 SSE：

```bash
curl -N http://localhost:8090/v1/query \
  -H 'Content-Type: application/json' \
  -d '{"conversation_id":"c1","message":"hello","stream":true}'
```

## 接入真实大模型

1. 复制 `service/agent-service-demo/apiconfig_example.json` 为 `apiconfig.json` 并填写密钥（亦可参考 [agent-core-java examples](https://gitcode.com/openJiuwen/agent-core-java) 仓内 `examples/`）。
2. 任选一种方式指定文件：`openjiuwen.service.llm.config-file`、`OPENJIUWEN_API_CONFIG`，或在
   `auto-discover=true` 时放到当前工作目录至向上 6 层范围内。
3. 重启 demo；链路变为 `Query → Orchestrator → JiuwenCoreAgentHandler → Runner → LlmAgent`。

配置文件选择优先级为“显式 Spring 路径 > `OPENJIUWEN_API_CONFIG` > 自动发现”。文件加载后，非空的
`openjiuwen.service.llm.*` Spring 配置按字段优先于 `apiconfig.json`。

详见 [agent-service-demo/README.md](../../../service/agent-service-demo/README.md)。
